# KOCOTREE 店铺页面 Excel

在用户提供的原 Excel 中完成店铺页面资料整理，不另建交付工作簿。优先保留模板原貌，并把每项新增内容与款式一一对应。

开始编辑前必须完整阅读 [references/rules.md](references/rules.md)。

## 工作流程

1. 检查原工作簿的可见工作表、隐藏工作表、活动工作表、合并单元格、既有列和文案格式。
2. 记录原始显隐状态；不得显示隐藏工作表，也不得创建无关工作表。
3. 以品名和款式名称查找资料，不以商品 ID 作为匹配条件。
4. 按参考文件规定的来源顺序查找模特图、素材图、场景图和卖点资料。
5. 只补缺失的品名短卖点，保留所有已有卖点原文。
6. 按海报、热门分类、专区的不同规则写入图片路径和文案。
7. 直接更新用户指定的原 Excel；若文件正在 WPS 中打开且存在未保存修改，先保存、关闭并重新读取最新版，再写回。
8. 完成后做内容和视觉复核，确认文字未跨单元格溢出，红色款式在 WPS 中实际可见，工作表显隐未改变。

## 关键实现约束

- 必须使用电子表格工作流处理 `.xlsx`，不要把表格内容复制到新的无关文件中。
- WPS 对单元格内局部富文本颜色兼容不稳定。需要“款式标红”时，款式必须单独占一行或单元格，并对整个款式单元格应用红色字体；不要依赖同一单元格内仅首行标红。
- 海报标题所在单元格必须开启自动换行，不能让文字溢出到图片路径列。
- 不得覆盖用户在 WPS 中尚未保存的修改。发现标题带 `*` 时先保存，再基于保存后的文件继续。
- 网络盘路径写入前尽量验证可访问性。无法访问百度网盘网页时，不绕过安全限制；使用用户已同步或下载到本地的资料，必要时说明限制。
- 最终验证至少包括：关键单元格内容、字体颜色、自动换行、路径替换、未找到项、可见/隐藏工作表和活动工作表。
