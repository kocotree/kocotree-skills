# NAS 与产品资料

## 路径配置

标准 NAS 根路径由环境变量 `KOCOTREE_NAS_ROOT` 或 `scripts/config/business_paths.json` 提供，环境变量优先。

业务目录由根路径和相对目录组合：

```text
产品信息：<NAS根目录>\产品中心\产品信息
合格证：<NAS根目录>\产品中心\合格证\合格证（正确
```

业务资料使用 IP 形式的 UNC 路径。映射盘符输入在运行时解析为对应 UNC 路径，报告记录归一后的路径。

## 访问与安全

- 使用 Windows 当前登录身份或凭据管理器访问共享目录。
- 配置、日志和报告不记录 NAS 用户名、密码或访问令牌。
- NAS 源文件只读访问；图片处理和质检在本地临时目录执行。
- 报告记录源 UNC 路径、本地工作目录和最终输出路径。

## 产品信息匹配

1. 在 `.xlsx`、`.xls` 和 `.xlsm` 文件名、工作表及记录中精确匹配产品货号。
2. 使用产品名称复核货号匹配结果。
3. 同一货号对应多个 Excel 时列出候选，不自动选择。
4. 从唯一记录读取中文面料、部位、颜色、尺码和合格证所需字段。
5. 英文面料不作为中文面料的替代来源。

## BarTender 匹配

按产品货号、产品名称、颜色和尺码缩小候选范围。优先选择 `110` 码；没有 `110` 时选择同一颜色的最小可用尺码。候选不唯一或产品身份不一致时停止导出。

BarTender 源文件以只读方式打开并导出，关闭时不保存。导出前后核对源文件大小、修改时间和只读属性。

## 本地工作副本

- 原始包复制到系统临时目录下的独立任务目录。
- 保留源文件与工作副本的对应清单。
- 任务结束后仅清理本次创建且已确认位于临时根目录内的工作目录。
