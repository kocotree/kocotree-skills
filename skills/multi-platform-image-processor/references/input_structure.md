# 输入结构

```text
产品目录或数据包
├─ 主图（或商品主图、产品主图）
├─ SKU（或sku、规格图、颜色图）
├─ 白底图（或白底、白背景图、白底图片）
├─ 透明图（或透明底、透明底图、透明背景图、免抠图）
├─ 详情（或详情页、详情图、产品详情）
└─ 素材图（或场景图、场景、素材）
```

```text
产品目录
├─ 主图
│  ├─ 800
│  ├─ 750
│  └─ 1440
├─ SKU
│  ├─ 800
│  └─ 1440
├─ 白底图
├─ 透明图
├─ 详情
│  └─ <图片文件>
└─ 素材图（或场景图）
```

```text
产品目录
└─ 数据包
   ├─ 主图
   │  ├─ 800
   │  ├─ 750
   │  └─ 1440
   ├─ SKU
   │  ├─ 800
   │  └─ 1440
   ├─ 白底图
   ├─ 透明图
   ├─ 详情
   │  └─ <图片文件>
   └─ 素材图（或场景图）
```

```text
产品目录或数据包
└─ SKU
   ├─ 加赠品
   │  ├─ 800
   │  └─ 1440
   └─ 无赠品
      ├─ 800
      └─ 1400
```

```text
产品目录或数据包
└─ SKU
   ├─ <业务分支>
   │  ├─ 800
   │  │  └─ <图片文件>
   │  └─ 1440
   │     └─ <图片文件>
   └─ <业务分支>
      ├─ 800
      │  └─ <图片文件>
      └─ 1440
         └─ <图片文件>
```

```text
产品目录或数据包
├─ SKU
│  ├─ <业务分支>
│  │  └─ <图片文件>
│  └─ <业务分支>
│     └─ <图片文件>
├─ 白底图
│  ├─ <业务分支>
│  │  └─ <图片文件>
│  └─ <业务分支>
│     └─ <图片文件>
└─ 透明图
   ├─ <业务分支>
   │  └─ <图片文件>
   └─ <业务分支>
      └─ <图片文件>
```

```text
产品目录或数据包
└─ 详情
   └─ 静态
      └─ <图片文件>
```

```text
产品目录或数据包
└─ 详情
   └─ 静态
      ├─ 上
      │  └─ <图片文件>
      └─ 下
         └─ <图片文件>
```
