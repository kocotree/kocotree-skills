# 输入结构

```text
产品目录
├─ 主图
│  ├─ 800
│  ├─ 750
│  └─ 1440
├─ SKU
│  ├─ 800
│  └─ 1440
├─ 白底图
├─ 透明图
├─ 详情
│  └─ <图片文件>
└─ 素材图
```

```text
产品目录
└─ 数据包
   ├─ 主图
   │  ├─ 800
   │  ├─ 750
   │  └─ 1440
   ├─ SKU
   │  ├─ 800
   │  └─ 1440
   ├─ 白底图
   ├─ 透明图
   ├─ 详情
   │  └─ <图片文件>
   └─ 素材图
```

```text
产品目录或数据包
└─ SKU
   ├─ 加赠品
   │  ├─ 800
   │  └─ 1440
   └─ 无赠品
      ├─ 800
      └─ 1400
```

```text
产品目录或数据包
└─ 详情
   └─ 静态
      └─ <图片文件>
```

```text
产品目录或数据包
└─ 详情
   └─ 静态
      ├─ 上
      │  └─ <图片文件>
      └─ 下
         └─ <图片文件>
```
