# Agent 视觉复核任务

## 默认策略

复杂视觉判断由 Agent 在完整流程前后完成：

- 脚本负责确定性处理、模型去字、尺寸压缩和结构化报告。
- 脚本在报告中写入 `Agent复核建议`。
- Agent 根据 `Agent复核建议` 查看对应图片并判断是否需要重新运行脚本或调整规则。

## 内部执行上下文

Agent 调用脚本时使用以下隐藏参数传递视觉定位结果：

- `--material-plan`：详情页面料区域 JSON 路径。
- `--detail-plan`：逐张检查后的详情页模块分类与水平拆分 JSON 路径。
- `--size-table-source`：实际尺码表所在详情图，使用输入产品目录内相对路径或绝对路径。
- `--size-table-box`：排除标题和外框后的完整尺码表坐标，格式为 `left,top,right,bottom`。
- `--visual-review-approved`：本轮任务包含三张业务图片原尺寸视觉复核。

这些参数由 Agent 构建并维护，不属于业务用户输入。

## 任务一：详情页模块检查与排序

每个产品的详情源图都要逐张检查。模块固定顺序为：

1. 品牌背书。
2. KV 主视觉。
3. 适用图标。
4. 产品信息。
5. 尺码表。
6. 图标说明。
7. 其他卖点、面料、认证、模特、品牌故事和店铺模块。

`品牌背书`、`KV`、`适用图标`、`产品信息`、`尺码表`、`图标说明` 六类模块全部存在时才可进入平台派生。同类模块保持源图中的相对顺序。

适用图标卡片与下方说明连在同一张图时，在卡片下方纯背景间隔处水平拆分，卡片的上下边框和圆角完整保留。分段覆盖原图全部高度，区域连续且不重叠。

详情模块计划格式：

```json
{
  "详情模块": [
    {"类型": "品牌背书", "图片": "详情/静态/<文件名>.jpg"},
    {"类型": "适用图标", "图片": "详情/静态/<文件名>.jpg", "区域": [0, 0, 790, 800]},
    {"类型": "图标说明", "图片": "详情/静态/<文件名>.jpg", "区域": [0, 800, 790, 1500]}
  ]
}
```

`图片` 使用相对于数据包根目录的路径。整图模块省略 `区域`；连体图使用 `[left, top, right, bottom]` 表示保留原宽的水平分段。计划覆盖所有详情源图。

平台图片生成后以原尺寸检查模块齐全、顺序、空白、重复和切分边界。

## 任务二：站外 SKU 去文字质量判断

使用场景：

- 生成 `站外通用版\800sku去除文字` 后。

判断目标：

- 逐张以原始尺寸并排查看原图与输出图，不能只看缩略联系图。
- 右侧商品卡片彩色标签中的目标文字是否被去除。
- 彩色标签的颜色、渐变、纹理、轮廓、圆角和弧形是否保持原样。
- 白色商品卡片、商品图、人物、手部、背景、画布边缘和图片四角是否保持原样。
- 是否新增任何色块、边框、图形、文字、涂抹或装饰。
- 模型调用成功不代表视觉验收通过；任何目标文字区域外的肉眼可见变化均判定不合格。

## 任务三：透明图裁边质量判断

使用场景：

- 京东 `透明图`。
- 唯品会 `1200透明图`。

判断目标：

- 京东透明图主体是否在 `800x800` 透明画布内贴合最长边，并由额外 4px 放大产生轻微边缘裁切。
- 唯品会透明图是否先提取主体，等比例放入 `1200x1200` 工作图，再按产品裁切，最后主体额外放大 `10px` 且最终输出仍保持一边为 `1200px`。
- 是否保留透明通道。
- 是否误裁主体或仍保留明显透明空边。

## 任务四：详情页面料定位与复核

使用场景：完整流程检查详情页面料时。

判断目标：

- 找全详情页中材质、面料和成分信息区域。
- 确认目标区域原有字号、颜色、字重、字距、行距和对齐方式。
- 修改后文字内容与 Excel 中文原文一致，混合字体位于统一基线。
- 原尺寸叠加比较修改前后图片，目标区域外没有肉眼可见变化。

## 任务五：实际尺码表选择与裁切

使用场景：

- 生成尺码图前。

判断目标：

- 选择包含衣长、胸围、裤长、腰围、臀围、脚口、袖长或肩宽等测量数据的实际尺码表。
- 排除尺码快选、试穿推荐和仅含推荐身高体重的表格。
- 裁切区域保留完整表头、全部行列、左右边界和底部尺码行。
- `STEP3选尺码`、`Size` 等标题及外层灰色边框不进入最终裁切图。

## 任务六：业务图片排版复核

使用场景：

- 合格证图、吊牌图和尺码图生成后。

判断目标：

- 合格证主体完整并在画布中居中。
- 吊牌图主体完整、清晰且不含面料。
- 尺码图中的合格证和尺码表完整，尺码表在可读前提下尽量放大。
- 三张图为白底且没有软件界面、水印、光标、选中框、多余边框或裁切缺失。
