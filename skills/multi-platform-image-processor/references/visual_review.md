# Agent 视觉定位与复核

## 内部上下文

Agent 在运行前将视觉定位结果写入一个 UTF-8 JSON，通过隐藏参数 `--context` 传入：

```json
{
  "面料计划": "<面料区域计划绝对路径>",
  "详情计划": "<详情模块计划绝对路径>",
  "颜色命名": {
    "白底图/1.jpg": "颜色名称",
    "透明图/1.png": "颜色名称"
  },
  "尺码表图片": "详情/<实际相对路径>/<文件名>.jpg",
  "尺码表区域": [0, 0, 790, 600],
  "尺码单位文字": "cm",
  "合格证面料完整": false,
  "合格证面料锚点": [1200, 800],
  "合格证面料字号": 48
}
```

## 详情页模块

逐张检查详情源图，按以下顺序组织模块：

1. 品牌背书。
2. KV 主视觉。
3. 图标说明，存在时使用。
4. 产品信息。
5. 产品规格，非服装产品存在时使用。
6. 尺码表，服装产品存在时使用。
7. 尺码快选，存在时使用，包括身高体重与推荐尺码的明确对应关系、用户试穿尺码和试穿反馈。
8. 其他卖点、面料、认证、模特、品牌故事和店铺模块。

按详情页实际存在的模块组织顺序，缺少的模块直接跳过。同类模块以及其他卖点、面料、认证、模特、品牌故事和店铺模块保持源图相对顺序。连体图从纯背景间隔处水平拆分，分段连续覆盖原图高度，不重叠且保留卡片边框和圆角。

### 产品信息与尺码识别

- 同时包含名称、货号、材质、颜色或尺码的基础信息卡归为产品信息；其中的材质文字继续按 Excel 中文面料规则检查和修正。
- 非服装产品的尺寸、容量、重量、型号、部件、结构、部件材质、接口或配件说明归为产品规格；多张产品规格图保持源图相对顺序并连续排列。
- 包含实际尺码、围度数据或测量方法的页面归为尺码表；页面同时包含颜色展示时保持整张图片。
- 身高体重与推荐尺码存在明确对应关系，或包含用户试穿尺码、试穿反馈的页面归为尺码快选。
- 模特姓名、身高、体重等人物资料归为模特；带有“模特 SHOW”“模特展示”等标题的页面与后续连续人物穿戴图组成一个连续模特模块，整体保持源图相对顺序。
- 以材质性能或面料特点为主体的独立卖点页面归为面料。
- 产品信息与实际存在的产品规格、尺码表或尺码快选组成连续模块，不插入其他卖点。

### 图标说明识别

- 生成详情计划前查看 [图标说明-示例.jpg](../assets/图标说明-示例.jpg)。
- 图标说明采用横向功能或安全类别图标组的模块形态；图标数量、颜色和文案以当前产品为准。
- 图标说明与 KV 位于同一张源图时，沿两者之间的纯色边界切成独立的全宽模块，完整保留图标卡片边框和圆角。
- 产品信息及实际存在的产品规格、尺码表、尺码快选依次紧跟图标说明；没有图标说明时直接紧跟 KV。
- 普通卖点海报归入其他卖点；连续源图保持原始相对顺序和相邻关系。
- 生成后确认产品信息和实际存在的产品规格或尺码相关模块连续，其他卖点没有插入其中。

## 面料区域

- 找全材质、面料和成分区域，记录原文、坐标、颜色、背景色和水平内边距。
- 详情页不存在独立材质、面料或成分字段时，面料计划记录为空列表。
- 每个面料计划项使用 `右侧字段参考区域` 记录至少两个上下相邻字段的右侧文字区域，优先包含名称、货号、颜色和尺码。
- Pillow 从参考区域测量共同右边界，从原材质文字测量字高和行距；面料计划不填写字号、行距或右边界坐标。
- 只在已确认的纯色背景上局部重绘。
- 修正后原尺寸对比，确认内容、混合字体基线、排版和非目标区域。
- 确认重复的外层 `面料：` 已省略，括号使用英文括号。
- 重绘后由 Pillow 复测字高与右边界；确认括号内容、数字和百分号没有跨行，材质各行与上下字段形成同一条右侧竖直基准线。

## 颜色命名

- 平铺白底图和透明图逐张对照 SKU 图片，确认对应的 SKU 颜色名称。
- 业务分支内的白底图和透明图按所在相对目录归类，文件名沿用分支内的源文件名。
- 内部上下文使用相对图片路径记录平铺素材颜色；颜色名称与 SKU 文件名一致。

## 尺码表与业务图片

- 选择实际测量表，定位排除标题和外框后的完整表格区域。
- 从同一详情源图确认尺码表实际单位，并将单位文字记录为内部上下文；不换算或推测单位。
- 生成后的单位按 `/<实际单位>` 格式绘制在尺码表右上角，字号为 `24px`，并与表格右边界对齐；上方合格证主体宽度为尺码表宽度的 `80%`。
- 在 BarTender 导出主体坐标系中定位“等级”字段正下方的面料锚点和相邻正文字号。
- 生成合格证前查看 [合格证-示例.jpg](../assets/合格证-示例.jpg)。等级下方能够完整容纳面料时使用该位置；无法容纳时按价格、面料、经销商地址的顺序在左下方竖向排列。
- 以材质组成项是否齐全判断原合格证面料完整性，不要求原文与 Excel 逐字一致。记录 `合格证面料完整`；值为 `true` 时保留原合格证内容，值为 `false` 时记录面料锚点和字号并补充 Excel 中文面料。
- 生成后以原尺寸确认三张图片完整、清晰、居中，尺码单位可见，不含软件界面、水印、光标、选中框、多余边框或裁切缺失。

## 透明图

- 京东透明图主体在 `800×800` 透明画布内贴合最长边，额外放大 `4px` 后主体完整。
- 唯品会透明图保持一边 `1200px`，额外放大 `10px` 后主体完整。
- 两者保留透明通道，不误裁主体，不保留明显透明空边。

## 站外 SKU 去字

- 脚本识别右侧商品卡片或底部横向彩色标签，构建模型输入、计算差异并回贴标签内部。文字由生图模型移除。
- 标签裁片受保护区域的明显变化比例上限为 `15%`，平均通道差异上限为 `10`；标签内部非文字底图变化比例上限为 `15%`。
- 数值超限时保留每次候选的最终回贴预览，由 Agent 对比原图后选择候选或原图。
- 模型未返回图片、文件无法读取或宽高比错误时使用原图。
- Agent 检查目标文字是否清除，标签颜色、渐变、纹理、轮廓、圆角和弧形是否保持，以及卡片、商品、人物、手部、背景和画布边缘是否正常。
- 程序在对应交付位置暂存原图，候选预览是符合交付尺寸和大小的 JPG。
- Agent 选候选图时将候选预览覆盖到对应交付图；选原图时保留当前交付图。复核结论直接显示在 Codex 页面。
