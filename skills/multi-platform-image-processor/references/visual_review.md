# Agent 视觉定位与复核

## 内部上下文

Agent 在运行前将视觉定位结果写入一个 UTF-8 JSON，通过隐藏参数 `--context` 传入：

```json
{
  "面料计划": "<面料区域计划绝对路径>",
  "详情计划": "<详情模块计划绝对路径>",
  "尺码表图片": "详情/静态/<文件名>.jpg",
  "尺码表区域": [0, 0, 790, 600],
  "合格证面料锚点": [1200, 800],
  "合格证面料字号": 48
}
```

## 详情页模块

逐张检查详情源图，按以下顺序组织模块：

1. 品牌背书。
2. KV 主视觉。
3. 适用图标。
4. 产品信息。
5. 尺码表。
6. 图标说明。
7. 其他卖点、面料、认证、模特、品牌故事和店铺模块。

前六类模块全部存在。同类模块保持源图相对顺序。连体图从纯背景间隔处水平拆分，分段连续覆盖原图高度，不重叠且保留卡片边框和圆角。

## 面料区域

- 找全材质、面料和成分区域，记录原文、坐标、字号、颜色、背景色、内边距和行距。
- 只在已确认的纯色背景上局部重绘。
- 修正后原尺寸对比，确认内容、混合字体基线、排版和非目标区域。

## 尺码表与业务图片

- 选择实际测量表，定位排除标题和外框后的完整表格区域。
- 在 BarTender 导出主体坐标系中定位“等级”字段正下方的面料锚点和相邻正文字号。
- 生成后以原尺寸确认三张图片完整、清晰、居中，不含软件界面、水印、光标、选中框、多余边框或裁切缺失。

## 透明图

- 京东透明图主体在 `800×800` 透明画布内贴合最长边，额外放大 `4px` 后主体完整。
- 唯品会透明图保持一边 `1200px`，额外放大 `10px` 后主体完整。
- 两者保留透明通道，不误裁主体，不保留明显透明空边。

## 站外 SKU 去字

- 脚本只识别右侧商品卡片、构建模型输入、计算差异和回贴标签内部。文字由生图模型移除。
- 右侧裁片受保护区域的明显变化比例上限为 `15%`，平均通道差异上限为 `10`；标签内部非文字底图变化比例上限为 `15%`。
- 数值超限时保留每次候选的最终回贴预览，由 Agent 对比原图后选择候选或原图。
- 模型未返回图片、文件无法读取或宽高比错误时使用原图。
- Agent 检查目标文字是否清除，标签颜色、渐变、纹理、轮廓、圆角和弧形是否保持，以及卡片、商品、人物、手部、背景和画布边缘是否正常。
- Agent 选定最终结果后写入交付目录，复核结论直接显示在 Codex 页面。
