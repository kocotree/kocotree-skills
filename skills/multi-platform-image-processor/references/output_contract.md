# 输出与完成约定

## 产品交付目录

```text
产品目录名_YYYYMMDD-HHMMSS
├─ 天猫通用版
│  └─ 吊牌图.jpg
├─ CBME
├─ 蜂享家＋爱库存
│  └─ 尺码图
│     └─ 尺码图.jpg
├─ 产品货号 产品名称-京东
├─ 唯品会
│  └─ 合格证.jpg
└─ 站外通用版
```

产品交付目录只包含上述六个平台目录。

同一产品的一次任务只发布一个交付目录。六平台图片和业务图片先在 Skill 内部运行目录生成并验收，通过后整体发布到用户输出根目录。重试过程、候选图、报告和日志不进入用户输出目录。

## 内部运行产物

```text
scripts/output/runs
└─ <时间戳>-<货号>
   ├─ staging
   │  └─ <产品目录名_时间戳>
   ├─ report.json
   ├─ image-records.jsonl
   ├─ run.log
   └─ candidates
      └─ <SKU 模型输入、候选图和回贴预览>
```

- 每次任务只生成一份内部完整报告，保存产品匹配、面料检查、BarTender 导出、平台结果、业务图片、复核建议、风险和失败项。
- 逐图明细每行记录一张输出图的来源、用途、尺寸、格式、大小和处理动作。
- 日志记录关键流程节点、外部工具调用、异常和降级。
- 发布成功后删除本轮 `staging`；失败任务的暂存产物保留在对应内部运行目录供排查。
- Agent 复核结论仅在 Codex 页面输出。产品交付目录中不得创建、复制、移动或另存报告、逐图明细、日志、上下文或 Agent 复核记录。
- `scripts/output/runs` 总容量上限为 `1 GiB`。超过上限时按时间删除最旧的完整运行目录，当前正在执行的运行目录不参与清理。用户输出目录不参与容量清理。

## 问题级别

- `警告`：数量等可量化规则不完全满足，文件已输出。
- `风险`：结果需要 Agent 视觉判断。
- `失败项`：文件无法读取、无法写出、大小超限或关键业务资料缺失。

能继续的图片保持输出，单个文件失败不中断其他图片。

## 完成状态

- `完成`：交付产物完整，没有失败项或待复核项。
- `部分完成`：交付产物已生成，存在待 Agent 复核项。
- `失败`：存在未完成的失败项。

Agent 读取完整报告，按复核建议查看原图、输出图和候选预览，将最终结论直接显示在 Codex 页面。
