# 输出与完成约定

## 产品交付目录

```text
产品目录名_YYYYMMDD-HHMMSS
├─ 天猫通用版
├─ CBME
├─ 蜂享家＋爱库存
├─ 产品货号 产品名称-京东
├─ 唯品会
├─ 站外通用版
├─ 合格证
│  └─ 合格证图.jpg
├─ 吊牌图
│  └─ 吊牌图.jpg
└─ 尺码图
   └─ 尺码图.jpg
```

产品交付目录只包含上述九个业务目录。

## 内部运行产物

```text
scripts/output
├─ report
│  ├─ <货号>-时间-report.json
│  └─ <货号>-时间-image-records.jsonl
├─ logs
│  └─ <货号>-时间.log
└─ image-without-text-tmp
   └─ <SKU 模型输入、候选图和回贴预览>
```

- 每次任务只生成一份内部完整报告，保存产品匹配、面料检查、BarTender 导出、平台结果、业务图片、复核建议、风险和失败项。
- 逐图明细每行记录一张输出图的来源、用途、尺寸、格式、大小和处理动作。
- 日志记录关键流程节点、外部工具调用、异常和降级。
- Agent 复核结论仅在 Codex 页面输出。产品交付目录中不得创建、复制、移动或另存报告、逐图明细、日志、上下文或 Agent 复核记录。
- 报告、日志和 SKU 临时图各保留最近 `100` 份或张。

## 问题级别

- `警告`：数量等可量化规则不完全满足，文件已输出。
- `风险`：结果需要 Agent 视觉判断。
- `失败项`：文件无法读取、无法写出、大小超限或关键业务资料缺失。

能继续的图片保持输出，单个文件失败不中断其他图片。

## 完成状态

- `完成`：交付产物完整，没有失败项或待复核项。
- `部分完成`：交付产物已生成，存在待 Agent 复核项。
- `失败`：存在未完成的失败项。

Agent 读取完整报告，按复核建议查看原图、输出图和候选预览，将最终结论直接显示在 Codex 页面。
