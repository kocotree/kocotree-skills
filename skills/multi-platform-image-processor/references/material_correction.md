# 详情页面料检查与修正

## 内容依据

- 使用产品信息 Excel 中的中文面料、成分和部位信息。
- 扫描详情页全部材质、面料和成分区域，核对成分名称、含量比例和部位关系。
- 比较时忽略空格、加号、顿号、斜杠以及“面料”“材质”等提示文字。
- 发现实质差异时使用 Excel 中文原文；内容不翻译、不简化、不推测。

## 处理范围

- 完整流程在平台派生前检查详情页面料。
- 原始产品数据包只读访问；存在差异的详情图写入任务临时目录并作为平台详情页来源。
- 任务临时目录在平台派生完成后自动清理，不进入最终交付目录。
- 只重绘面料文字区域，保护商品图、背景、Logo、图标、装饰元素和其他文字。
- 输出不增加灰色边框。

## 字体角色

字体从 Skill 的 `assets` 目录加载，映射由 `scripts/config/font_roles.json` 提供：

| 内容 | 字体 |
|---|---|
| 中文与百分号 | 方正兰亭中黑 |
| 数字和小数点 | G8321 SemiBold |
| 数字 `1` | 阿里妈妈方圆体 SemiBold |
方正兰亭中黑备用字体仅在配置明确指定时使用。渲染前校验字体内部名称和目标字形；必需字体或字形缺失时停止文字重绘并写入失败项。

## 排版要求

- 混合字体字符使用同一基线。
- 字号、视觉字重、颜色、字距、行距与原详情页一致。
- 多行文字保持原有对齐关系，底部和左右边界排列规范。
- 修改前后对比非目标区域；出现非目标像素变化时判定为失败。

## 视觉定位职责

脚本负责内容规范化、字体加载、局部重绘和差异统计。Agent 负责定位全部面料区域、确认原版式参数、检查文字是否完整覆盖，以及对修改前后图片进行原尺寸视觉复核。无法可靠确定文字区域时记录 Agent 复核项，不覆盖原图。

Agent 将定位结果写入内部 UTF-8 JSON 上下文。图片使用输入产品目录下的相对路径：

```json
{
  "面料区域": [
    {
      "图片": "数据包/详情/静态/601.jpg",
      "识别原文": "棉90% 氨纶10%",
      "区域": [120, 860, 1880, 1040],
      "字号": 48,
      "颜色": [32, 32, 32],
      "背景色": [255, 255, 255],
      "内边距": [0, 0],
      "行距": 8
    }
  ]
}
```

`区域` 为允许修改的 `left, top, right, bottom`；`背景色` 使用目标文字下方已确认的纯色背景。具有纹理或渐变的区域不得使用纯色清除，工作流将该区域列为失败项并保留原图。
