# 业务处理规则

## 产品资料来源

- 固定查询“产品资料-码-对外”和“产品资料-款-对外”，连接与字段映射见 `scripts/config/product_sources.json`。
- 按字段使用码表、款表、NAS Excel 的优先级；已有有效值保持不变，缺失值由下一来源补充。
- 码表提供货号、品名、成分、颜色规格、尺寸；款表提供货号和品名。款表中的合格证图片不参与制作。
- 空白和单独的 `/`、`／`、`-`、`—` 视为缺失；只有英文的成分视为缺少中文材质。
- 按货号精确匹配。每表选择一条记录：优先名称相符、资料完整的记录，再按记录 ID 稳定排序。整次任务使用同一组已选记录和合并资料。
- 当前制作需要的货号、正式名称、中文面料、代表颜色齐全时直接使用多维表资料；存在缺项时读取一份 NAS Excel，仅补充缺失字段。规格与尺码随选中记录保留。
- 多维表查询使用 `lark-cli base +record-list --as user`。身份授权或访问失败时先恢复读取能力；空查询结果与字段缺失进入 NAS 补缺流程。
- Agent 制作视觉计划前，通过 `common.product_sources.resolve_product_data(货号, 名称, resolve_business_paths().product_info_root)` 获取资料；主流程使用同一解析逻辑。字段及来源写入唯一内部报告的 `产品匹配`，中文面料写入 `面料检查.中文原文`。
- SKU 素材及平台目录以输入产品包为准，不依据所选业务资料筛选款式或分支。

## NAS 与 Excel 补缺

- NAS 根路径由 `KOCOTREE_NAS_ROOT` 或 `scripts/config/business_paths.json` 提供，环境变量优先。
- 产品信息目录为 `<NAS根目录>\产品中心\产品信息`。
- 合格证目录为 `<NAS根目录>\产品中心\合格证\合格证（正确`。
- 业务资料使用 IP 形式的 UNC 路径；映射盘符输入在运行时转换为 UNC 路径。
- NAS 和原产品数据包只读访问，凭据不写入配置、日志或报告。

1. 在 `.xlsx`、`.xls`和 `.xlsm` 中精确匹配产品货号。
2. 同一产品存在多个候选时，按文件路径、工作表和行号稳定排序，选择第一条记录补缺。
3. 多维表的正式名称优先；NAS 按货号匹配，名称差异不覆盖多维表名称。
4. 内部报告记录实际选中的文件、工作表、行号及各字段来源。

## 详情页面料

- 检查详情页全部材质、面料和成分区域，各区域使用选定资料的中文原文重绘。
- 完整提取各段中文组成项，跳过英文译文，保留中文行中的化学符号。中文原文不翻译、简化或推测。
- 中文、百分号和标点使用方正兰亭中黑，普通数字使用 G8321 SemiBold，所有数字 `1` 使用阿里妈妈方圆体 SemiBold。
- `面料：` 后紧接另一个带冒号的层级名称时省略外层 `面料：`。
- 中文括号统一为英文括号；括号及其内部文字保持同一行，数字与百分号保持同一行。
- 面料文字按语义整体换行，每一行与上下相邻字段的右侧文字使用同一右边界。
- 字号、行距和右边界依据原材质文字及上下相邻字段的实际像素测量结果确定。
- 字号、字重、颜色、字距和行距保持原版式。
- 只重绘面料文字区域；商品图、背景、Logo、图标、装饰和其他文字保持不变。
- 修正图使用任务临时目录参与平台生成，产品数据包保持原样。

## BarTender 匹配与导出

- 合格证主体固定从 NAS 的 `.btw` 文件导出。
- 使用合并资料的正式产品名称匹配合格证一级目录。
- 代表颜色取所选资料的颜色字段；没有独立字段时取首个规格中数字尺码之前的颜色文本。
- 候选范围是产品目录顶层的 `.btw` 文件。优先选择代表颜色的 `110` 码；没有 `110` 时选择该颜色最小可用尺码。
- 候选不唯一时停止导出并列出候选。
- 只读打开选中的 `.btw` 并导出，不保存或覆盖源文件。

## 合格证图

- 输出 `唯品会\合格证.jpg`，尺寸 `750×1600`，白底竖版。
- 合格证已覆盖产品需要标示的全部材质组成时保留原内容，不要求与产品资料逐字一致；缺少组成项时补充合并资料的中文面料原文。
- 合格证新增面料采用与详情页面料一致的字符字体规则，优先位于右侧信息栏“等级”字段正下方，与信息栏左侧对齐。
- “等级”下方无法完整容纳面料时，将面料放在左下角价格下方，并按价格、面料、经销商地址的顺序竖向排列；面料字号为 `20px`、行距为 `6px`，面料与经销商地址间距为 `6px`。
- 将 [合格证-经销商地址.jpg](../assets/合格证-经销商地址.jpg) 等比例放入合格证内容区左下方。
- 合格证主体、面料与经销商地址组成整体并居中，长文本在信息栏内换行，不加边框。

## 吊牌图与尺码图

- 输出 `天猫通用版\吊牌图.jpg`，尺寸 `800×800`，白底，只放合格证或吊牌主体，不附加面料。
- 输出 `蜂享家＋爱库存\尺码图\尺码图.jpg`，尺寸 `800×800`，组合合格证或吊牌与详情页实际尺码表，不附加面料。
- 尺码图上方合格证主体宽度为下方尺码表宽度的 `80%`，两者整体居中。
- 实际尺码表优先包含衣长、胸围、裤长、腰围、臀围、脚口、袖长或肩宽等数据。
- 排除尺码快选、试穿推荐和仅含推荐身高体重的表格。
- 尺码表不含 `STEP3选尺码`、`Size` 等标题和外层灰色边框，保留完整表头、全部行列、底部尺码行和左右边界。
- 尺码图右上角按 `/<实际单位>` 格式绘制同一详情源图使用的尺码单位，字号为 `24px`，并与尺码表右边界对齐。
- 实际尺码表缺少明确单位时，由 Agent 重新确认尺码表数据源。
