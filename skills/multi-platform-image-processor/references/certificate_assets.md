# 合格证相关图片

## 生成范围与选择

- 每个产品固定生成合格证图、吊牌图和尺码图。
- 每个产品生成一套图片，不按全部颜色重复生成。
- 代表颜色取产品信息 Excel 的明确颜色字段，或首个规格中数字尺码之前的颜色文本。
- 优先选择 `110` 码；没有 `110` 时选择该颜色最小可用尺码，并在报告中记录。

## BarTender 来源

按产品信息 Excel 的正式产品名称匹配合格证一级目录，从该目录顶层按代表颜色和尺码匹配现有 `.btw` 文件。存在多个无法消歧的候选时停止导出并列出候选。

以只读方式打开文件并导出高分辨率合格证内容。源文件的内容、时间戳和属性保持不变。导出图不含软件界面、选中框、光标、打印预览水印和多余背景。

## 合格证图

输出 `合格证\合格证图.jpg`：

- 尺寸 `750×1600`，白底竖版。
- 文件大小不超过 `500KB`。
- BarTender 合格证主体完整显示并在画布中居中。
- 不附加详情页中文面料块，不遮挡条码、规格、尺码、价格或其他字段。

## 吊牌图

输出 `吊牌图\吊牌图.jpg`：

- 尺寸 `800×800`，白底。
- 文件大小不超过 `500KB`。
- 只放清晰的合格证或吊牌内容，不加入面料信息。
- 主体完整显示且尽量放大。

## 尺码图

输出 `尺码图\尺码图.jpg`：

- 尺寸 `800×800`，白底。
- 文件大小不超过 `500KB`。
- 组合合格证或吊牌内容与详情页实际尺码表，不加入合格证面料块。
- 优先选择包含衣长、胸围、裤长、腰围、臀围、脚口、袖长或肩宽等实际测量数据的表格。
- 排除尺码快选表、试穿表和仅含推荐信息的表格。
- 去除表格上方的 `STEP3选尺码`、`Size` 等标题和表格外层灰色边框。
- 保留完整表头、全部行列、底部尺码行和左右边界，在内容完整的前提下尽量放大。

找不到 BarTender 文件、实际尺码表或无法保证表格完整时，将对应图片写入失败项，不生成占位图。

Agent 在执行前确认实际尺码表详情图和排除标题、灰框后的完整表格坐标，并作为内部上下文传给脚本。三张图片生成后，Agent 以原始尺寸复核内容完整性、清晰度和排版。
