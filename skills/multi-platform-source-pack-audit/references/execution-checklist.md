# 执行检查清单

按款执行并逐项记录，不使用“整体看过”代替明确状态。

## 输入与台账

- [ ] 已确认输入为视觉部原始数据包。
- [ ] 已进入 Skill 的 `scripts` 目录，并使用该目录下的 `uv.lock` 和 `.venv` 运行脚本。
- [ ] 已将本次运行产物放入 `scripts/work/<任务标识>`，并完成200 MiB容量检查。
- [ ] 运行期间只向当前任务工作目录和最终飞书报告写入产物。
- [ ] 已记录审核范围、商品数量、货号、款名、品类、颜色和适用平台。
- [ ] 已访问产品信息、静物拍摄 2026 和检测报告三个 NAS 目录，或明确记录无法读取的目录。
- [ ] 已生成全量文件台账和汇总 JSON。
- [ ] 已运行 `run_ocr.py`，`ocr-results.json` 的图片数与台账图片数一致。
- [ ] 已生成逐图 OCR 文字块、坐标、置信度、全文、候选范围和标注复核图。
- [ ] 已生成 `source-pack-naming-audit.json`，并复核十项目录与文件命名检查结果。
- [ ] 已生成四边和内部接缝辅助审阅图，`edge-review-manifest.json` 的图片数与配置适用图片数一致。
- [ ] 产品信息为 `.xls` 时，已使用 `extract_xls.py` 只读提取为 JSON，并核对源文件哈希、工作表和单元格数据。
- [ ] 台账中的目录数、空目录、图片总数、其他文件数、损坏文件和重复分组已复核。
- [ ] 已按货号或款式、模块补充台账分类，并确认每张图片的专项状态字段均可追踪。
- [ ] 已判断每张图片是否包含材质文案，并填写材质依据、核对结果、差异和证据字段。
- [ ] 已按当前检查项打开对应历史错误示例，且没有用历史图片替代当前款证据。
- [ ] 已读取字体专项配置、阿里妈妈方圆体 SemiBold 字体文件和静态标准字形参考图。
- [ ] 已检查汇总文件的 `typography_resources` 状态和错误；资源不可用时已标记“待补证”并继续其他检查。
- [ ] 未在审核任务中创建、替换或修改 Skill 内的脚本、配置、参考资料和资源文件。

## 原始包目录与文件命名

- [ ] 根目录可按 `{款号} {商品名称}` 解析。
- [ ] `主图`、`SKU`、`白底图`、`透明底`、`详情`、`素材图` 六个一级目录均存在且名称正确。
- [ ] 每张图片均放在对应素材类型目录。
- [ ] 主图、SKU 和素材图的尺寸目录名称与图片实际像素一致。
- [ ] 白底图、透明底和 SKU 文件均使用具体颜色名称。
- [ ] 白底图、透明底和 SKU 的颜色名称集合一一对应。
- [ ] 透明底文件为带 Alpha 透明通道的 PNG。
- [ ] 主图、详情图和素材图编号均可解析。
- [ ] 已检查重名、重复编号和无法识别的名称。
- [ ] 已检查同一素材系列的扩展名和命名格式一致性。
- [ ] 详情编号连续性和主图不同尺寸版本的文件名同步关系未纳入检查。

## 主图、SKU、白底图和透明图

- [ ] 已逐张检查商品款式、颜色、正反面、细节和当前款一致性。
- [ ] 已逐张检查主体完整性、裁切、拉伸、变形、模糊、水印、文字和错品素材。
- [ ] 已专项检查主图边缘贴合、异常空隙、画面错位、主体越界和商品遮挡。
- [ ] 已核对 SKU 图内品名、规格、色名和商品身份字段。
- [ ] 已检查白底图的背景、灰边、脏点、残影和阴影。
- [ ] 已验证透明图的 Alpha，并目视检查抠破、白黑边、锯齿、脏点和残留背景。
- [ ] 已完成同款同色跨模块横向比较。

## 详情页

- [ ] 已按实际顺序拼接完整长图并完成上下文联审。
- [ ] 已检查顺序、模块衔接、重复、缺失和错品。
- [ ] 已检查画面中的模块编号、跳号、倒序、重复编号和编号内容对应关系。
- [ ] 已逐张检查原始切片的文字、Logo、商品画面和遮挡。
- [ ] 已检查人物、商品或装饰模块的错位、未贴合和关键信息遮挡。
- [ ] 已逐张按上、右、下、左检查四边。
- [ ] 每张适用图片的上、右、下、左四个结构化状态均已填写，四边完成数等于适用图片数乘以 4。
- [ ] 已检查连续品牌横条左右两端。
- [ ] 已检查 1–3 px 非设计性白边、窄边和导出错位。
- [ ] 每张详情图的内部接缝状态均已填写，并检查模块白缝、断层和未贴合。
- [ ] 已按有效视觉损失判定边缘问题：关键结构缺失列为错误，影响不明确进入人工复核，仅触边且不影响阅读和画面效果时通过。
- [ ] 已检查切片高度小于等于 1600 像素。
- [ ] 已完成详情页四边二次复核。

## 字体与数字 `1` 专项

- [ ] 已按 [typography-review.md](typography-review.md) 遍历当前款全部详情页原始切片。
- [ ] 已定位标题、正文、尺码、百分比、标准编号、报告编号和其他组合中的每一次数字 `1`。
- [ ] 已对 OCR 未识别但目视可见的数字 `1` 补充定位。
- [ ] 已将每一次数字 `1` 与阿里妈妈方圆体 SemiBold 标准字形比较，检查轮廓、字重、基线和相邻字符一致性。
- [ ] 已记录数字 `1` 的发现数量、已检查数量、异常数量和未检查数量。
- [ ] 已确认“发现数量 = 已检查数量 + 未检查数量”，且未检查数量为零。
- [ ] 同一字体问题合并时，已列出全部受影响文件、位置、上下文和异常数量。

## 文字、资料和合规

- [ ] 已按 [ocr-review.md](ocr-review.md) 对照原图逐张复核 OCR 全文和文字框。
- [ ] 每张图片的 `ocr_human_verified` 均为 `true`；OCR 失败图片已完成人工降级转录。
- [ ] OCR 原文与人工转录不一致时，已在 `ocr_review_notes` 记录关键修正。
- [ ] 已使用同一份 OCR 结果完成违禁词、错别字、材质成分、尺码表、商品身份和执行标准六类适用专项。
- [ ] 每张图片均已判断文字状态为 `present`、`absent` 或 `unreadable`。
- [ ] 每张含文字图片均已完整转录可见文字，并完成错别字、漏字多字、语法和动词搭配四项结构化检查。
- [ ] 无文字图片的文字专项均标记为 `not_applicable`；文字不可辨认图片已记录原因和处理方式。
- [ ] 已检查中文错别字、漏字、多字、语法、语义、动词搭配、英文拼写、数字和标点。
- [ ] 已检查字体、字号、粗细、颜色、字距、行距、基线和同层级文案一致性。
- [ ] 已检查换行、断句、词组拆分、标点位置和上下行阅读顺序。
- [ ] 已检查文字完整性、切断、遮挡、裁边、缺笔画和出界。
- [ ] 已核对全部单位与对应项目或物理量。
- [ ] 已核对尺码表名称、表头、数值、单位、行列关系和已有脚注内容。
- [ ] 已核对身高、体重字段的数值和单位；仅口径存疑的项目已标记“需审查”。
- [ ] 已核对货号、品名、品类、颜色、尺码、执行标准、安全类别、等级和成分信息。
- [ ] 已核对品牌成立时间、品牌年限和跨图片宣传表述。
- [ ] 已核对产品信息表、详情页、水洗唛及随包资料的成分名称、比例和部位关系。
- [ ] 已将每处材质文案与当前款具体面料成分信息表核对；具体明细没有被“其他”概括替代。
- [ ] 已核对 Logo 的形状、颜色、比例、方向、版本、字样、组合关系和落位。
- [ ] 已核对检测宣传与报告的样品身份、项目、数值、单位、结论和限定条件。
- [ ] 已检查广告法、极限词、证据型宣传和适用平台专项规则。
- [ ] 已运行 `scan_prohibited_terms.py`；平台或类目未知时已扫描全部平台规则。
- [ ] 已逐条复核 `prohibited-term-audit.json`，填写处理状态、完整语境、说明和证据路径。
- [ ] 已对全部含文字图片执行 OCR 候选扫描并逐张复核原图。
- [ ] 已检查大小写、全半角、空格、标点、换行、同义表达、拆字、谐音和字母数字混写。
- [ ] 驳回词涉及质检报告、证书或专利号时，已核对证明材料与当前商品及宣传项目一致。
- [ ] 功能性或性能性主张缺少对应证明时，已标记“待补证”，并写明需要补充的报告编号、页码、检测项目和适用范围。
