# 各平台驳回词与处理规则

## 判定方法

- 先确认商品适用平台和产品类目，再应用对应规则；“通用”规则覆盖该平台的全部类目。
- 商品适用平台或产品类目尚未确认时，平台专项规则命中项标记为“待补证”，不得直接判为已确认错误。
- 对主图、SKU、白底图、透明图、详情页、合格证、尺码图和素材图中的可见文字执行 OCR，并逐张核对原图。
- 忽略大小写、全半角、空格、标点和换行造成的形式差异，同时检查同义表达、拆字、谐音和字母数字混写。
- 结合完整语境判断词语用途。证书、质检报告或专利号属于规则要求的证明材料时，核对材料与当前商品、宣传项目及适用范围是否一致。
- 功能性、性能性或检测性主张缺少对应证明，或证明范围不足以支持文案时，标记为“待补证”，并记录需要补充的报告编号、页码、检测项目和适用范围。
- 每个命中项记录平台、类目、图片路径、命中文字、上下文、规则、处理建议和证据图。
- 同一图片影响多个平台时，在同一问题下列出全部受影响平台及各平台处理要求。

## 京东自营

| 产品／类目 | 驳回词与处理规则 |
|-|-|
| 通用 | “其他家”“其他品牌”属于商业拉踩对比，可改为“普通”“普通××”；“赠”“送”改为“下单即享”或删除；“权威”改为“专业”；避免“久……不累”类表述；避免“1亿妈妈”“97W+妈妈”等夸大数据。 |
| 太阳镜／泳镜 | “防眩晕”可改为“不眩晕”；“不伤眼”可改为“护眼”；不得使用“保护视力”“不累眼”。 |
| 防晒帽 | “降温”可改为“可降”“清凉”或“凉爽”。 |
| 冬款 | “蓄热”可改为“蓄暖”；不得使用“调温”；“升温”可改为“加温”或“温升”；“自发热”可改为“会发热”。 |
| 鞋子 | “防滑”需要质检依据；没有质检依据时可改为“防摔”或“稳稳的抓地力”；不得使用“不累脚”。 |
| 书包 | “护脊”可改为“减压”；不得使用“保护脊柱”“不伤脊椎”“久背不累”；使用“专利”时注明专利号。 |
| 服饰类 | 不得使用“荧光剂”“荧光”“致敏”“权威”“国家级”；“甲醛”需要质检依据。 |
| 通用 | 删除包退换、质保类承诺；不得使用“第一”，具有对应证明材料时标记待人工复核。 |
