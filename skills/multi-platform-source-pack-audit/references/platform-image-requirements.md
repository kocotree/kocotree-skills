# 各平台图片规格

## 核对方法

- 先确认图片的适用平台和图片类型，再应用对应规格。
- 使用台账中的真实像素和字节数核对尺寸与文件大小，不根据文件名推断。
- 同一图片类型列出多个尺寸时，任一列明尺寸均可作为合格值。
- 同时核对切片数量、编号、命名和版式备注；规格表标为“未注明”的项目不推测数值。
- 每个不符合项记录平台、图片类型、文件路径、实际值、要求值、版式问题、处理建议和证据。
