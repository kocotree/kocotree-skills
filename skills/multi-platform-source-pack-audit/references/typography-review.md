# 字体与字形专项检查

## 配置与参考

- 从 [字体专项配置](../assets/configs/typography-profiles.json) 读取检查范围、目标字体、目标字重、关注字符和字体文件。
- `detail-digit-1-alimama-fangyuan-semibold` 配置适用于全部详情页切片。目标字体为阿里妈妈方圆体，目标字重为 SemiBold，标准字体文件为 `assets/fonts/阿里妈妈方圆体-SemiBold.ttf`，标准参考图为 `assets/typography-references/detail-digit-1-alimama-fangyuan-semibold.png`。
- 打开配置指定的标准字体文件和标准字形参考图。两项资源均可读取后，才能作出字体符合或异常的结论。
- 从 `inventory-summary.json` 的 `typography_resources` 读取配置状态、资源错误和可用配置数量。
- OCR 和视觉识别只用于定位候选字符，不能单独证明字体或字重。

## 全量定位

1. 按展示顺序遍历当前款全部详情页原始切片。
2. 定位所有关注字符，不限于标题、正文或检测报告区域。
3. 数字 `1` 的检查范围包括独立数字，以及 `10A`、`17年`、尺码、百分比、标准编号、报告编号等组合中的每一次出现。
4. 对候选位置记录文件相对路径、图片序号、坐标或可复现的版面位置、上下文和识别置信情况。
5. OCR 未识别但目视可见的数字 `1` 必须补入台账。

## 字形判定

- 将每个数字 `1` 与标准字形参考图比较，检查笔画轮廓、起收笔、倾斜、宽高比例、字重、基线以及与相邻数字或字符的字体一致性。
- 字形特征明确不符合目标字体或目标字重时，标记为“已确认错误”。
- 图片分辨率、压缩、透视、特效或遮挡导致无法可靠区分时，标记为“待人工复核”，不得推测字体。
- 标准字体文件或标准字形参考图无法读取时，在台账和报告中标记为“待补证”，记录失败路径和原因，并继续其他检查。审核任务中不创建或替换 Skill 内的字体资源。
- 数字 `5`、`6` 不属于字形专项检查范围。

## 闭环统计

每款至少记录以下统计：

- 发现数量：详情页中所有关注字符的出现次数。
- 已检查数量：已完成标准字形比对的出现次数。
- 异常数量：已确认字体或字重不符合的出现次数。
- 未检查数量：发现数量减去已检查数量。

统计关系必须满足：

`发现数量 = 已检查数量 + 未检查数量`

完成字体专项检查时，未检查数量必须为零。异常数量不得大于已检查数量。

完成台账填写后，将适用图片的 `typography_reference_status` 填为 `checked`，并在 `scripts` 目录运行：

```powershell
uv run python .\validate_typography_review.py ".\work\<任务标识>\inventory.csv" --summary-output ".\work\<任务标识>\typography-review-summary.json"
```

校验命令成功退出后，字体专项才具备完成状态。

## 问题合并与报告

- 同一字体问题在多张图片或多个位置重复出现时，可以合并为一个问题项。
- 合并问题必须列出全部受影响文件、每个文件的出现位置、上下文和异常数量，不能只列代表图。
- 证据图可以使用有代表性的清晰截图，但报告中的影响范围必须覆盖所有命中位置。
- 报告同时写明配置编号、目标字体、目标字重、关注字符、发现数量、已检查数量、异常数量和未检查数量。
